Hackathon Judge Demo Script

Interactive 4-step walk-through demonstrating every acceptance criterion.

Step 1

Start on trusted home network

On home Wi-Fi, the app applies speed-first routing. Fast sites stay Direct. Only ISP-throttled sites (like youtube.com) route via WireGuard VPN because VPN is measured >10% faster.

Step 2

Simulate joining untrusted public Wi-Fi

Press 'Join public Wi-Fi'. Notice how all normal web sites immediately flip to the teal VPN tunnel for protection. Crucially, banking sites (HDFC, SBI) stay safely on Direct with encrypted DNS, preventing banking fraud app blocks!

Step 3

Run a before and after speed test

Proves our claim with hard numbers: execute a real test burst to show round-trip milliseconds saved per request.
